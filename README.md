## 💡 Overview

A logic programming project modeling an electronics store with product facts, classification rules, and example queries. Created for a university course in logical and functional programming.

## 📌 Features

- Product facts containing a name, category, and price.
- Rules for identifying affordable products and price categories.
- Recommendations constrained by a budget.
- Recursive calculation of a shopping list's total price.
- List filtering through pattern matching and recursion.
- Five example query goals demonstrating the model.

## 🛠 Tech Stack

**Language and concepts:** Prolog, facts, rules, lists, recursion, pattern matching, cut, and fail.

## 📂 Project Structure

The repository contains the original `.spj` project file and a Bulgarian coursework document explaining the facts, rules, queries, and expected results.

## 🚀 Explore the Project

Read the coursework document for the program listing and sample goals. Open the `.spj` file in its compatible original development environment. A standalone `.pl` file and a verified command-line setup are not included in this repository.

## 🧪 Project Status

**Public Project Files · University Project.** This is a small declarative model, not a deployed online store. The README describes the supplied coursework material; no new runtime compatibility testing is claimed.
